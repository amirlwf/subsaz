# ساب‌ساز — زیرنویس دقیق کلمه‌به‌کلمه، آفلاین

فایل ویدیو یا صوت بده، فایل `srt` دقیق بگیر.
رونویسی کاملا لوکال با `faster-whisper` — بدون API و بدون آپلود.

## دانلود

از صفحه [Releases](../../releases):

| فایل | چیه |
|---|---|
| `SubSaz-Setup-x.y.z.exe` | نصاب ویندوز (شورتکات + آن‌اینستالر) |
| `SubSaz-portable-win64.zip` | پرتابل — زیپ را باز کن و `SubSaz.exe` را اجرا کن |

> اگر دانلود مدل ناموفق بود، به VPN وصل شو و دوباره تلاش کن —
> مدل‌ها روی HuggingFace هستند که تحریم است. خود برنامه هم این را می‌گوید.

## اولین اجرا (۲ دقیقه)

1. برنامه را باز کن.
2. **بخش ۲ (سیستم و مدل)** را ببین: برنامه سیستم تو را اسکن می‌کند
   (CPU / رم / کارت NVIDIA) و بهترین مدل را پیشنهاد می‌دهد.
3. **⬇ دانلود مدل** را بزن و تایید کن — فقط یک‌بار، بعدش کاملا آفلاین.
4. فایل اضافه کن → استایل زیرنویس را انتخاب کن → **▶ ساخت زیرنویس**.

## انتخاب خودکار مدل

| سیستم تو | انگلیسی | فارسی |
|---|---|---|
| گرافیک NVIDIA با ۸GB+ | دقیق‌ترین (turbo) | دقیق‌ترین (turbo) |
| گرافیک متوسط | small | دقیق‌ترین (turbo) |
| CPU قوی | small | دقیق‌ترین (turbo) |
| CPU ضعیف | small | اول base سریع، اگر اطمینان کم بود خودکار turbo |

سیستم ضعیف همان دقت را می‌گیرد، فقط کندتر.
می‌توانی مدل را دستی هم قفل کنی (`auto` = انتخاب خودکار).

## استایل‌های زیرنویس

- **single** — تک‌خطی (استایل شورت و تیک‌تاک)
- **two** — دوخطی مثل ادوبی پریمیر
- کلمه در خط (۱ تا ۶)، حداکثر حروف در خط (۲۰ تا ۵۰)
- گپ و مکث قابل تنظیم (خط چشمک نمی‌زند)
- کلمات خاص (اسم برند و اصطلاحات درست رونویسی می‌شوند)
